## ✨ Features

### 🎨 Design & UI
- **Fully Responsive** — adapts seamlessly across mobile, tablet, and desktop
- **Smooth Scroll Navigation** — sticky navbar with anchor-based routing
- **Animated Role Ticker** — looping marquee of job titles in the hero section
- **Interactive Skill Cards** — hover-reveal descriptions for each technology
- **Modern Layout** — clean grid-based sections with thoughtful spacing

### 🧭 Navigation
- Fixed top navbar with smooth scroll to all sections
- Mobile hamburger menu for compact screens
- Highlighted active links

### 🗂️ Sections
- **Hero** — Full-screen intro with name, animated roles, country, age & location stats, and CTA buttons
- **About Me** — Personal bio with professional summary
- **Experience** — Student & Full Stack Intern experience cards
- **Education** — Timeline of academic achievements from O/L to BSc (Hons)
- **Skills (Tech Stack)** — 9 technologies with icon cards and detailed skill descriptions
- **Tools Stack** — 8 developer tools including VS Code, IntelliJ, Docker, Figma
- **Projects** — 4 featured projects with descriptions and GitHub links
- **Blog / Hire Me** — Call-to-action section outlining what clients gain
- **Contact** — Social links (GitHub, LinkedIn, WhatsApp, Instagram) + contact form

### 📬 Contact Form
- Name, email, and message fields
- Reset & Submit actions
- Direct email link: `rayanofficial2004@gmail.com`

## 🚀 Getting Started

No installation needed. Just clone and open.

```bash
# Clone the repository
git clone https://github.com/RayanKavishka/myPortfolio.git

# Navigate into the project
cd myPortfolio

# Open in your browser
open index.html
```

Or simply drag `index.html` into any modern browser.
